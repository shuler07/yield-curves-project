Yield Curves API

API отдаёт историю кривых бескупонной доходности Мосбиржи. При локальном запуске адрес сервера — http://127.0.0.1:8000.

Формат запроса

Оба эндпоинта используют GET с параметрами в строке запроса. Тело запроса отсутствует.

ПараметрФорматНазначение
dateYYYY-MM-DDОдна дата.
date_fromYYYY-MM-DDНачало диапазона включительно.
date_toYYYY-MM-DDКонец диапазона включительно.
scenario_versionСтрока, 1–64 символаНеобязательный идентификатор версии стресс-сценариев. Применяется к /curves/processed.

Передайте date отдельно или пару date_from и date_to. Начало диапазона должно быть не позже конца.

curl 'http://127.0.0.1:8000/curves/raw?date=2026-10-30'
curl 'http://127.0.0.1:8000/curves/processed?date_from=2026-10-26&date_to=2026-10-30'
curl 'http://127.0.0.1:8000/curves/processed?date=2026-10-30&scenario_version=irrbb_v1_a6a304e2d32aba4c'

Формат ответа

Успешный ответ возвращается с кодом 200 и типом application/json.

ПолеТип JSONЗначение
date_from, date_toСтрокиЗапрошенные границы в формате YYYY-MM-DD. Для date обе границы равны этой дате.
missing_datesМассив строкЗапрошенные календарные даты, для которых в ответе нет снимков.
snapshotsМассив объектовСнимки, упорядоченные по дате и времени котировки. За день может быть несколько снимков.

Каждый снимок содержит curve_date в формате YYYY-MM-DD и quote_time в формате HH:MM:SS с возможной дробной частью секунды. Смещение часового пояса отсутствует.

Общее поле точкиТип JSONЗначение
tenorДесятичная строкаСрок в годах. "0.250000" соответствует трём месяцам.
yield_rateДесятичная строкаСтавка в долях единицы. "0.1406" соответствует 14,06 %.
etl_run_idСтрока UUIDИдентификатор запуска, записавшего точку. По нему можно найти запись в etl_runs.

В десятичных строках используется точка. Точки в каждой кривой отсортированы по возрастанию tenor.

GET /curves/raw

Снимок содержит массив points с исходными наблюдениями Мосбиржи. Обычно в снимке 12 точек. Если для срока нет ставки, соответствующая точка отсутствует.

Пример ответа с одной показанной точкой

{
  "date_from": "2026-10-30",
  "date_to": "2026-10-30",
  "missing_dates": [],
  "snapshots": [
    {
      "curve_date": "2026-10-30",
      "quote_time": "18:54:59",
      "points": [
        {
          "tenor": "1.000000",
          "yield_rate": "0.1406",
          "etl_run_id": "e2bdcb6e-466f-4feb-883e-7547cf36130d"
        }
      ]
    }
  ]
}

GET /curves/processed

Снимок содержит массив curves с семью кривыми по 19 точек. В каждой кривой есть scenario, scenario_version и массив points.

Значения scenario в порядке выдачи — Baseline, Parallel_Up, Parallel_Down, Short_Up, Short_Down, Steepener и Flattener.

У Baseline поле scenario_version равно null. Все шесть стресс-сценариев одного снимка имеют общую версию. Если запросить данные без явной версии, для каждого снимка выбирается последний полный набор по времени начала ETL.

Дополнительное поле точкиТип JSONЗначение
discount_factorДесятичная строкаКоэффициент дисконтирования по формуле (1 + yield_rate)^(-tenor).
is_interpolatedЛогическое значениеtrue, если базовая ставка в этой точке получена интерполяцией.
is_extrapolatedЛогическое значениеtrue, если базовая ставка в этой точке получена экстраполяцией.

Сокращённый пример ответа с одной кривой и одной точкой

{
  "date_from": "2026-10-30",
  "date_to": "2026-10-30",
  "missing_dates": [],
  "snapshots": [
    {
      "curve_date": "2026-10-30",
      "quote_time": "18:54:59",
      "curves": [
        {
          "scenario": "Baseline",
          "scenario_version": null,
          "points": [
            {
              "tenor": "1.000000",
              "yield_rate": "0.1406000000",
              "etl_run_id": "e2bdcb6e-466f-4feb-883e-7547cf36130d",
              "discount_factor": "0.876731544800981939",
              "is_interpolated": false,
              "is_extrapolated": false
            }
          ]
        }
      ]
    }
  ]
}

Загрузка и ошибки

Если по запрошенным датам нет данных, оба эндпоинта запускают ETL и ждут результата. Для /curves/processed дата без полного снимка тоже считается пропущенной. При успешной загрузке ETL сохраняет исходные и обработанные кривые даже при запросе к /curves/raw.

При отсутствии котировок API возвращает 200, доступные снимки и список оставшихся пропусков. Если весь диапазон пуст, snapshots равен [].

Код HTTPПричинаПоле detail
404Для дозагрузки /curves/processed не найдена полная калибровка указанной версии.Строка.
422Ошибка формата или сочетания параметров либо версия сценариев не поддерживается расчётным слоем.Массив ошибок при проверке формата параметров. Строка при проверке сочетания дат или версии.
502Загрузка или расчёт завершились ошибкой, и в ответе остались пропуски.Объект с сообщением, запусками ETL с ошибками и отсутствующими датами.
503PostgreSQL недоступен или схема БД не обновлена.Строка.
504Истекло время ожидания уже выполняющейся загрузки.Строка.

Пример ответа HTTP 502

{
  "detail": {
    "message": "Не удалось загрузить или рассчитать часть дат; подробности в etl_runs",
    "runs": [
      {
        "etl_run_id": "e2bdcb6e-466f-4feb-883e-7547cf36130d",
        "status": "failed",
        "date_from": "2026-10-30",
        "date_to": "2026-10-30"
      }
    ],
    "missing_dates": ["2026-10-30"]
  }
}

В runs возможны статусы failed и partial_success. Успешно загруженные даты остаются в базе. /curves/raw возвращает 200, если для каждой запрошенной даты есть исходный снимок, даже при сбое расчёта обработанных кривых.
