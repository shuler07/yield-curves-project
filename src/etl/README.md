# Yield Curves Data Pipeline

Этот проект собирает исторические данные по кривым доходности с сайта Мосбиржи и объединяет выгруженные архивы в одну итоговую таблицу.

## Состав проекта

- `parse.py` — автоматизирует загрузку архивов с сайта MOEX через браузер Selenium.
- `merge.py` — распаковывает скачанные ZIP-архивы, объединяет CSV-данные по `tradedate` и `tradetime` и формирует итоговый файл `downloads/merged_zcyc_ranges.csv`.
- `requirements.txt` — зависимости проекта.

## Как работает `parse.py`

Скрипт:

1. Открывает страницу архива кривых доходности на MOEX.
2. Устанавливает диапазон дат и набор сроков (`TERM_ARRAY`).
3. Для каждого срока инициирует скачивание данных.
4. Сохраняет архивы в папку `downloads/`.

После запуска в каталоге `downloads/` появляются архивы `.zip`, которые затем обрабатываются скриптом слияния.

## Как работает `merge.py`

Скрипт:

1. Находит все архивы `.zip` в папке `downloads/`.
2. Распаковывает их в `downloads/unpacked/`.
3. Ищет CSV-файлы внутри архивов.
4. Находит строку с заголовком, где есть колонка `tradedate`.
5. Сохраняет значения по датам и времени в общий словарь.
6. Сортирует колонки по периодам (`period_...`).
7. Записывает итоговый файл `downloads/merged_zcyc_ranges.csv`.

Итоговая таблица имеет формат:

```csv
tradedate;tradetime;period_0.25;period_0.5;period_1;...
```

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python parse.py
python merge.py
```

## Важные замечания

- Для `parse.py` нужен установленный браузер Chrome/Chromium и соответствующий ChromeDriver.
- Скрипт работает в headless-режиме, поэтому запуск возможен без визуального окна браузера.
- Скрипт `merge.py` зависит только от стандартной библиотеки Python и не требует дополнительных пакетов, кроме тех, что указаны в `requirements.txt`.

## Результат

После завершения процесса в папке `downloads/` появится итоговый файл:

```text
downloads/merged_zcyc_ranges.csv
```

Это готовая таблица для дальнейшего анализа, визуализации или загрузки в pandas.
